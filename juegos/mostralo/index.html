Cómo se juega

  • Cada turno juega una persona de un equipo. Le pasan el celu y solo ella mira la consigna.
  • La ruleta dice cómo mostrarla: dibujando (sin letras ni números), con mímica (sin hablar ni hacer ruido) o tarareando (sin letra: solo "na-na", "tu-ru" o silbando).
  • Si su equipo adivina antes de que se acabe el tiempo, suma el punto (2 si la consigna es difícil y se juega en Mezcla).
  • Si se acaba el tiempo, los otros equipos tienen un intento cada uno para robar el punto.
  • En cada turno pasa otra persona, para que todos jueguen.
