Bingo
musical

El cartón tiene temas en vez de números. Uno pone la música, el resto marca cuando reconoce el tema.

Cómo se juega

  • El que pone la música abre Pongo la música, carga la playlist y muestra el QR. Cada uno lo escanea y le toca un cartón distinto.
  • El juego elige el próximo tema al azar; el anfitrión lo pone en su app (YouTube Music, Spotify o TIDAL) y lo deja sonar un rato, sin decir el nombre.
  • Los jugadores marcan en su celu el tema que reconocen. Ojo: en el cartón aparece solo el título.
  • Línea: fila, columna o diagonal completa. Bingo: cartón lleno.
  • El que canta le pasa su código al anfitrión, que lo verifica contra los temas que sonaron. Si marcó uno que no sonó, no vale.
  • Para que no se haga eterno: pasá cada tema al minuto, o apenas arranca el estribillo.

Armar la partida

1 · Playlist de YouTube o YouTube Music

La playlist tiene que ser pública o no listada. Los mixes automáticos ("Mix", "Radio") no se pueden leer.

Clave de YouTube (se carga una sola vez)

Para leer playlists hace falta una clave gratuita de Google. Queda guardada solo en este celu.

  1. Entrá a YouTube Data API v3 en Google Cloud con tu cuenta de Google. Si te pide, creá un proyecto (cualquier nombre).
  2. Tocá Habilitar.
  3. Andá a Credenciales → Crear credenciales → Clave de API.
  4. Recomendado: en la clave, Restricción de aplicaciones → Sitios web → silvestry1.github.io/*, y Restricción de API → YouTube Data API v3.
  5. Copiá la clave y pegala acá arriba.

2 · O pegá la lista (Spotify, TIDAL, lo que sea)

Un tema por renglón, como Título - Artista. En el cartón va solo el título. También podés importar un CSV exportado de Spotify (Exportify) o de TuneMyMusic (sirve para TIDAL).
